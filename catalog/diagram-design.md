## 推荐理由

为架构图、流程图等提供有明确视觉规范的 HTML / SVG 输出，适合文档、方案讲解和分享材料。

## 什么时候用

例如：“使用 diagram-design，把这段登录流程整理成一张静态 HTML/SVG 流程图。”

产品页面及交互设计优先用 My Coding Skills 的 design；专门制作解释性图表时选这个插件。

## 使用与验证

上游声明支持多个 Agent；本市场只配置 Codex。已核对固定提交、插件 manifest 和 Skill 资源结构，尚未运行模型生成效果测试。原始输出以 HTML/SVG 为主，其他格式及依赖按上游说明使用。
